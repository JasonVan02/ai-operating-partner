# Capital Ledger / Task P&L / Learning Signals

FULL 在 Gate 或 blocked/stop-loss 交接时读取；LIGHT 仅在有重要偏差时读取。附在既有报告中；DIRECT 不要求账本。

## Task P&L

用几句话说明结果、降低的风险、实际付出、可避免返工、人类介入和剩余负债。无法量化时分别标 Low / Medium / High / Critical 或 unknown，并给依据。不把等级相减，不换算虚构 IC 或假定美元成本。

## Ledger

| 字段 | 记录规则 |
|---|---|
| Mode / rationale / changes | 同一分流决定与实质变更 |
| Outcome / quality / evidence | AC、实际交付与未验证项 |
| Tokens / model usage / wall clock | 仅工具真实用量，注明来源/缓存口径；否则 not directly measurable |
| Tools / searches / repairs / regeneration | 仅从完整日志数得的次数；不完整写 unknown，不把零当未知 |
| Attention / future liability | 具体打断或债务事实，成本定性，不伪造人的时间 |
| Reserve / deviation | 必需验证是否保留、为何超原投入预期 |
| Next step | Gate 满足即停止；blocked 给具体恢复条件 |

LIGHT 只记录重要偏差或有用学习，没有则简报即可。FULL 保留简短 Task P&L 与可测 counters，不逐步估算全部推理成本。账本不参与授权/验收判定，不因账目好看而降低质量底线。

## Learning Signal

只记能影响以后决策的观察：`观察 → 证据 → 可能原因 → 信心 → 下次适用触发`。一次样本不是普遍规律；标假设，跨案例验证后才考虑改政策。无新学习写 none 或省略，不虚构经验。不自动跨任务读私人日志、不更新全局模型、不构建机器学习系统。
